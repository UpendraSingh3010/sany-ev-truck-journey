# SANY funnel visual upgrade

## Goal
Replace the basic presentation with a more premium, modern SANY experience while preserving the approved red, navy, white and cyan brand system, the ten-stage comparison story, all supplied claims, and the demo-only quote form.

## Image placement
- Use the new three-truck lineup for **Choosing the truck** to communicate range choice and fleet scale.
- Use the new container truck in the mountain setting for **Energy & range**.
- Use the new truck at the DC charger for **Charging**.
- Use the new braking truck for **Energy recovery**.
- Keep the strongest existing product, highway, cabin, loaded-truck and tipper images in their relevant remaining stages.
- Tune each crop separately for desktop and mobile so the truck remains the visual focus.

## Official branding
- Replace both typed “SANY” blocks with the official `logo.webp` from SANY India’s website.
- Replace the template browser icon with SANY India’s official `favicon-1.png`, resized appropriately for the app.
- Preserve Roboto and the website-derived red, navy, white, pale-grey and restrained cyan palette.

## Premium interaction and depth
- Upgrade the opening section with subtle image scale, layered brand treatment and more confident entrance timing.
- Add refined image reveal, copy reveal and staggered metric animations as sections enter view.
- Add restrained image zoom, border movement, elevation and accent-line effects on stage imagery, specification cells, feature tags and model choices.
- Add directional motion to links and quote buttons, clearer focus feedback, and a smoother mobile navigation transition.
- Turn the five-system convergence area into a more dynamic visual sequence that leads the eye toward the complete truck.
- Keep motion professional and lightweight, and fully disable decorative movement when reduced motion is requested.

## Layout refinement
- Improve visual rhythm with stronger image proportions, more deliberate spacing, bolder section numbering and clearer contrast between “Without SANY” and “With SANY”.
- Preserve the alternating desktop composition while tightening the mobile reading order and avoiding cropped labels or overlapping content.
- Keep controls square and corporate rather than adopting rounded consumer-style cards.

## Technical details
- Store the four uploaded images and official logo through the managed asset flow.
- Keep the favicon as an optimized local browser-icon file and update the page head reference.
- Extend the existing intersection observer with stagger metadata rather than adding a heavy animation library.
- Verify desktop at 1280×1800 and mobile at 390×844, including navigation, section motion, hover/focus states, quote confirmation, image crops, overflow and browser-console errors.
